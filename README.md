# ProxyRelay - 二级代理管理器

一个基于C++的二级HTTP代理工具，支持用户认证、流量统计和实时监控。

## 功能特性

- **多端口代理**: 支持开放多个HTTP代理端口，每个端口可配置不同的上游代理
- **用户认证**: 基于用户名密码的HTTP Basic认证
- **IP限制**: 可限制用户只能从特定IP地址访问
- **流量控制**: 支持每日/每月流量限额
- **流量统计**: 实时显示上传/下载速度，记录每日流量使用情况
- **实时监控**: 图形化显示实时流量曲线
- **支持上游代理类型**: HTTP代理、SOCKS5代理

## 系统要求

- Windows 7/8/10/11 (64位)
- Visual Studio 2019 或更高版本
- CMake 3.15 或更高版本

## 编译步骤

### 1. 下载SQLite源码

从 https://www.sqlite.org/download.html 下载 `sqlite-amalgamation-*.zip`

解压后将以下文件放入 `libs/` 目录：
- `sqlite3.c`
- `sqlite3.h`

### 2. 创建应用图标（可选）

在 `resources/` 目录创建 `app.ico` 文件，或者删除 `app.rc` 中的图标引用。

### 3. 编译

运行 `build.bat` 或手动执行：

```batch
mkdir build
cd build
cmake .. -G "Visual Studio 17 2022" -A x64
cmake --build . --config Release
```

编译成功后，可执行文件位于 `build\Release\ProxyRelay.exe`

## 使用说明

### 启动程序

双击运行 `ProxyRelay.exe`，程序会自动创建 `proxy.db` 数据库文件。

### 添加代理端口

1. 切换到"端口配置"标签页
2. 点击"添加端口"按钮
3. 填写信息：
   - **监听端口**: 本地监听的HTTP代理端口（如8080）
   - **上游类型**: 选择 `http` 或 `socks5`
   - **上游地址**: 上游代理服务器IP地址
   - **上游端口**: 上游代理服务器端口
   - **上游用户名/密码**: 如果上游代理需要认证，填写此项
   - **描述**: 备注信息

### 添加用户

1. 切换到"用户管理"标签页
2. 点击"添加用户"按钮
3. 填写信息：
   - **用户名**: 登录用户名
   - **密码**: 登录密码
   - **允许IP**: 允许访问的IP地址，`*` 表示不限制，多个IP用逗号分隔，支持通配符如 `192.168.1.*`
   - **每日限额**: 每日流量限制（MB），0表示无限制
   - **每月限额**: 每月流量限制（MB），0表示无限制

### 启动服务

点击"启动服务"按钮，程序开始监听配置的端口。

### 客户端配置

在浏览器或应用程序中配置HTTP代理：
- 代理地址: `127.0.0.1`（或服务器IP）
- 代理端口: 配置的监听端口
- 认证: 使用添加的用户名和密码

### 查看流量

切换到"流量统计"标签页：
- 上方显示实时流量曲线图
- 下方显示各用户今日流量使用情况

## 默认用户

程序首次运行会创建默认用户：
- 用户名: `admin`
- 密码: `admin123`

请在使用前修改默认密码！

## 数据库

程序使用SQLite数据库存储配置和流量数据，数据库文件为 `proxy.db`。

### 数据表结构

- `users`: 用户信息
- `proxy_ports`: 代理端口配置
- `traffic_records`: 流量记录

## 注意事项

1. 如果需要监听1024以下的端口，需要以管理员权限运行程序
2. 流量统计每10秒自动保存一次到数据库
3. 关闭程序时会自动保存所有未保存的流量数据
